配套技术栈建议

你点名了 HTML5 + JS + Node + Vue，下面是我建议的组合。目标：内容用 Markdown 写，构建产物是纯静态，一键部署 GitHub Pages。

前端

  • Vue 3 + Composition API + TypeScript
  • Vite 构建（快、生态好、Pages 部署简单）
  • Vue Router 路由，Pinia 轻量状态
  • 原生 CSS 变量 + 少量 UnoCSS（可选）

内容层

  • Markdown + frontmatter 写文章（title/date/tags/status）
  • markdown-it 渲染 + Shiki 代码高亮
  • gray-matter 解析元数据，Vite 插件自动生成索引
  • 文章按 tags 自动归类：project / pitfall / changelog / retro

构建与数据

  • Node 脚本扫描 content/posts/*.md 生成 posts.json
  • 静态搜索：Pagefind 或 Fuse.js（无需后端）
  • RSS 用 Node 脚本生成 feed.xml
  • 可选：把项目元数据从各仓库 README 自动同步

部署

  • GitHub Actions → 构建 → 发布 gh-pages 分支
  • 或 /docs 目录 + Pages 设置
  • base: '/agentsBlog/' 别忘（就是那个坑）
  • 自定义域名 + CNAME 可选
关于"要不要用现成框架"： Astro / VitePress 写文档站更省事，但你要的是「能自己控制视觉」的博客， 而且点名了 Vue。所以建议 Vite + Vue 3 自建 —— 模板就是上面你选的那个风格， 把静态 HTML 拆成 Vue 组件即可，改造成本很低。
